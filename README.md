# Payroll Calculator

A Python payroll calculator that calculates regular pay, overtime pay, gross pay, tax deductions, retirement contributions, and net pay.
## Features

- Calculates regular pay
- Calculates overtime pay for hours over 80
- Calculates gross pay
- Accepts a user-entered tax percentage
- Calculates retirement contributions
- Calculates net pay
- Validates hourly rate, hours worked, tax rate, and retirement rate
## Skills Used

- Python
- Variables and data types
- User input
- Conditional statements (`if` / `else`)
- `while` loops
- Input validation
- Arithmetic calculations
- Percentage calculations
- f-string formatting
## How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code or another code editor.
4. Run the `payroll.py` file.
5. Enter the requested employee information when prompted.
